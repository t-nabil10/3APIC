III. Équations du type \(x^2 = a\)

Règles :
  • Si \(a < 0\) : l'équation \(x^2 = a\) n'a aucune solution.
  • Si \(a = 0\) : l'équation \(x^2 = 0\) a une seule solution : \(x = 0\).
  • Si \(a > 0\) : l'équation \(x^2 = a\) a deux solutions : \(x = \sqrt{a}\) et \(x = -\sqrt{a}\).
\[ x^2 = a \text{ avec } a > 0 \iff x = \sqrt{a} \text{ ou } x = -\sqrt{a} \]
Exemple 6 : Résoudre l'équation \(x^2 = 16\).
\(x^2 = 16\) avec \(16 > 0\). \(x = \sqrt{16}\) ou \(x = -\sqrt{16}\) \(x = 4\) ou \(x = -4\) x = 4 ou x = −4
