I. Équations du premier degré à une inconnue

1) Définition

Définition : Une équation est une égalité qui contient un ou plusieurs inconnues (souvent notées \(x\)).
Résoudre une équation, c'est trouver toutes les valeurs de l'inconnue qui rendent l'égalité vraie. Ces valeurs sont appelées les solutions.
\[ ax + b = 0 \quad (a \neq 0) \]
Équation du premier degré à une inconnue \(x\)
💡 Remarque : Une équation du premier degré a une seule solution (si \(a \neq 0\)).

2) Règles de résolution

Règles fondamentales :
  • On peut ajouter ou soustraire un même nombre aux deux membres d'une équation.
  • On peut multiplier ou diviser les deux membres par un même nombre non nul.
\[ a = b \iff a + c = b + c \]
\[ a = b \iff a \times c = b \times c \quad (c \neq 0) \]

3) Méthode de résolution

  1. Développer et simplifier les deux membres si nécessaire.
  2. Regrouper les termes en \(x\) dans un membre.
  3. Regrouper les constantes dans l'autre membre.
  4. Isoler \(x\) en divisant par son coefficient.
  5. Vérifier la solution en la remplaçant dans l'équation de départ.
Exemple 1 : Résoudre l'équation \(3x + 5 = 20\).
\(3x + 5 = 20\) On soustrait 5 aux deux membres : \(3x = 20 - 5\) \(3x = 15\) On divise par 3 : \(x = \dfrac{15}{3}\) \(x = 5\) Vérification : \(3 \times 5 + 5 = 15 + 5 = 20\) ✓ x = 5
Exemple 2 : Résoudre l'équation \(5x - 7 = 2x + 8\).
\(5x - 7 = 2x + 8\) On regroupe les \(x\) à gauche : \(5x - 2x = 8 + 7\) \(3x = 15\) \(x = \dfrac{15}{3} = 5\) Vérification : \(5 \times 5 - 7 = 18\) et \(2 \times 5 + 8 = 18\) ✓ x = 5
Exemple 3 : Résoudre l'équation \(2(x + 3) = 4x - 6\).
On développe : \(2x + 6 = 4x - 6\) On regroupe les \(x\) à gauche : \(2x - 4x = -6 - 6\) \(-2x = -12\) \(x = \dfrac{-12}{-2} = 6\) Vérification : \(2(6 + 3) = 18\) et \(4 \times 6 - 6 = 18\) ✓ x = 6
