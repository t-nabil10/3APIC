VII. Méthode générale de résolution

  1. Développer et simplifier les deux membres.
  2. Regrouper les termes en \(x\) d'un côté, les constantes de l'autre.
  3. Isoler \(x\) :
    • Pour une équation : diviser par le coefficient.
    • Pour une inéquation : diviser par le coefficient en changeant le sens si négatif.
  4. Écrire l'ensemble de solutions :
    • Équation : \(S = \{...\}\).
    • Inéquation : \(S = ]... ; ...[\) (intervalle).
  5. Vérifier la solution.

Résumé général

  • Équation : égalité avec une inconnue, solutions finies.
  • Règles : ajouter/soustraire un même nombre conserve l'égalité ; multiplier/diviser par un nombre non nul conserve l'égalité.
  • Équation produit : \(A \times B = 0 \iff A = 0\) ou \(B = 0\).
  • Équation \(x^2 = a\) : si \(a > 0\), \(x = \sqrt{a}\) ou \(x = -\sqrt{a}\).
  • Inéquation : inégalité avec une inconnue, solutions = intervalle.
  • Règle d'or : multiplier/diviser par un nombre négatif change le sens de l'inégalité.
  • Tableau de signes : méthode pour les inéquations produit.
💡 Conseils :
  • Vérifie toujours ta solution en la remplaçant dans l'équation ou l'inéquation de départ.
  • Pour les inéquations, fais attention au sens quand tu divises par un nombre négatif.
  • Pour les équations produit, n'oublie pas de traiter chaque facteur séparément.
  • Pour les inéquations produit, utilise un tableau de signes.
  • Écris l'ensemble de solutions avec les bons crochets (ouverts/fermés selon l'inégalité stricte ou large).
