VII. Méthode de résolution

  1. Identifier le type de droite : verticale, horizontale ou quelconque ?
  2. Pour une droite quelconque : poser \(y = ax + b\).
  3. Calculer \(a\) :
    • si deux points sont donnés : \(a = \dfrac{y_B - y_A}{x_B - x_A}\) ;
    • si la droite est parallèle à une autre : reprendre le \(a\) de l'autre droite.
  4. Calculer \(b\) : remplacer \(x\) et \(y\) par les coordonnées d'un point connu.
  5. Écrire l'équation finale : \(y = ax + b\).
  6. Vérifier : tester avec l'autre point (si disponible).

Résumé général

  • Droite verticale : \(x = k\).
  • Droite horizontale : \(y = k\).
  • Droite quelconque : \(y = ax + b\).
  • Coefficient directeur : \(a = \dfrac{y_B - y_A}{x_B - x_A}\).
  • Ordonnée à l'origine : \(b\) (intersection avec \((Oy)\)).
  • Point sur une droite : ses coordonnées vérifient l'équation.
  • Droites parallèles : même coefficient directeur \(a\).
  • Droite passant par l'origine : \(y = ax\) (fonction linéaire).
💡 Conseils :
  • Pour trouver l'équation d'une droite, tu as toujours besoin du coefficient directeur et d'un point.
  • Si on te donne deux points, commence toujours par calculer \(a\).
  • Si on te donne un point et le parallélisme avec une autre droite, reprends directement le \(a\) de cette droite.
  • Vérifie toujours ton équation en testant les points donnés dans l'énoncé.
  • Attention : une droite verticale n'a pas d'équation de la forme \(y = ax + b\).
