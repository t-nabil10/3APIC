Ordre et Opérations — 3ème Année Collège

I. Comparaison de deux nombres réels

Comparer deux nombres réels \(a\) et \(b\), c'est déterminer lequel est le plus grand, ou s'ils sont égaux. On utilise les symboles :

SymboleSignificationExemple
\(a < b\)\(a\) est strictement inférieur à \(b\)\(3 < 5\)
\(a \leq b\)\(a\) est inférieur ou égal à \(b\)\(3 \leq 3\)
\(a > b\)\(a\) est strictement supérieur à \(b\)\(7 > 2\)
\(a \geq b\)\(a\) est supérieur ou égal à \(b\)\(7 \geq 7\)

a) Différence et comparaison

\[ a < b \iff a - b < 0 \]
\[ a > b \iff a - b > 0 \]
\[ a = b \iff a - b = 0 \]

b) Comparaison de deux nombres relatifs

Règles :
  • Si deux nombres sont positifs, le plus grand est celui qui a la plus grande distance à zéro.
  • Si deux nombres sont négatifs, le plus grand est celui qui a la plus petite distance à zéro.
  • Un nombre positif est toujours plus grand qu'un nombre négatif.
Exemple : Comparer \(-5\) et \(-2\).
\(-5\) et \(-2\) sont tous les deux négatifs. La distance à zéro de \(-5\) est \(5\), celle de \(-2\) est \(2\). Comme \(5 > 2\), le plus petit (le plus à gauche sur la droite graduée) est \(-5\). −5 < −2

II. Ordre et opérations

1) Ordre et addition, ordre et soustraction

Règle : On peut ajouter (ou soustraire) un même nombre aux deux membres d'une inégalité sans changer le sens de l'inégalité.
\[ a < b \implies a + c < b + c \]
\[ a < b \implies a - c < b - c \]

Propriété d'addition membre à membre

\[ a < b \text{ et } c < d \implies a + c < b + d \]
💡 Attention : Cette propriété n'est valable que pour l'addition, pas pour la soustraction. On ne peut pas soustraire membre à membre deux inégalités de même sens.
Exemple : On sait que \(2 < x < 5\). Encadrer \(x + 3\) puis \(x - 4\).
Pour \(x + 3\) : on ajoute \(3\) aux trois membres. \(2 + 3 < x + 3 < 5 + 3\) \(5 < x + 3 < 8\) 5 < x + 3 < 8 Pour \(x - 4\) : on soustrait \(4\) aux trois membres. \(2 - 4 < x - 4 < 5 - 4\) \(-2 < x - 4 < 1\) −2 < x − 4 < 1

2) Ordre et opposé

Règle : Lorsque l'on multiplie par \(-1\) (c'est-à-dire que l'on prend l'opposé), le sens de l'inégalité change.
\[ a < b \implies -a > -b \]
Exemple : On sait que \(3 < 7\). Que peut-on dire de \(-3\) et \(-7\) ?
\(3 < 7\) On prend l'opposé : le sens change. \(-3 > -7\) −3 > −7

3) Ordre et multiplication

a) Multiplication par un nombre positif

Règle : Si on multiplie les deux membres d'une inégalité par un même nombre positif, le sens de l'inégalité ne change pas.
\[ a < b \text{ et } c > 0 \implies a \times c < b \times c \]

b) Multiplication par un nombre négatif

Règle : Si on multiplie les deux membres d'une inégalité par un même nombre négatif, le sens de l'inégalité change.
\[ a < b \text{ et } c < 0 \implies a \times c > b \times c \]

c) Multiplication membre à membre

\[ a < b \text{ et } c < d \text{ avec } a, b, c, d > 0 \implies a \times c < b \times d \]
💡 Attention : La multiplication membre à membre n'est valable que si tous les nombres sont positifs.
Exemple : On sait que \(2 < x < 5\). Encadrer \(3x\) puis \(-2x\).
Pour \(3x\) : on multiplie par \(3 > 0\), le sens ne change pas. \(3 \times 2 < 3x < 3 \times 5\) \(6 < 3x < 15\) 6 < 3x < 15 Pour \(-2x\) : on multiplie par \(-2 < 0\), le sens change. \(2 < x < 5 \implies -2 \times 2 > -2x > -2 \times 5\) \(-4 > -2x > -10\) Soit : \(-10 < -2x < -4\) −10 < −2x < −4

4) Ordre et inverse

Règle : Lorsque l'on prend l'inverse de deux nombres de même signe (tous deux positifs ou tous deux négatifs), le sens de l'inégalité change.
\[ 0 < a < b \implies \frac{1}{a} > \frac{1}{b} \]
\[ a < b < 0 \implies \frac{1}{a} > \frac{1}{b} \]
💡 Attention : On ne peut prendre l'inverse que de nombres non nuls, et il faut que les deux nombres soient de même signe.
Exemple : On sait que \(2 < x < 5\). Encadrer \(\dfrac{1}{x}\).
\(2 < x < 5\) avec \(x > 0\). On prend l'inverse : le sens change. \(\dfrac{1}{2} > \dfrac{1}{x} > \dfrac{1}{5}\) Soit : \(\dfrac{1}{5} < \dfrac{1}{x} < \dfrac{1}{2}\) 1/5 < 1/x < 1/2

5) Ordre et carré

Règles :
  • Si \(a\) et \(b\) sont positifs : \(a < b \implies a^2 < b^2\) (le sens ne change pas).
  • Si \(a\) et \(b\) sont négatifs : \(a < b \implies a^2 > b^2\) (le sens change).
\[ 0 \leq a < b \implies a^2 < b^2 \]
\[ a < b \leq 0 \implies a^2 > b^2 \]
Exemple : On sait que \(-3 < x < -1\). Encadrer \(x^2\).
\(-3 < x < -1\) avec \(x < 0\). Les nombres sont négatifs : le sens change pour le carré. \((-3)^2 > x^2 > (-1)^2\) \(9 > x^2 > 1\) Soit : \(1 < x^2 < 9\) 1 < x² < 9

6) Ordre et racine carrée

Règle : La fonction racine carrée est croissante sur \([0, +\infty[\). Donc pour deux nombres positifs, le sens de l'inégalité ne change pas.
\[ 0 \leq a < b \implies \sqrt{a} < \sqrt{b} \]
Exemple : On sait que \(4 < x < 9\). Encadrer \(\sqrt{x}\).
\(4 < x < 9\) avec \(x > 0\). La racine carrée conserve l'ordre. \(\sqrt{4} < \sqrt{x} < \sqrt{9}\) \(2 < \sqrt{x} < 3\) 2 < √x < 3

III. Encadrement

1- Définition

Encadrer un nombre \(x\), c'est trouver deux nombres \(a\) et \(b\) tels que :

\[ a < x < b \]

On dit que \(a\) est la borne inférieure et \(b\) la borne supérieure de l'encadrement. L'amplitude de l'encadrement est \(b - a\).

Exemple : \(3 < x < 7\) est un encadrement de \(x\) d'amplitude \(7 - 3 = 4\).

2- Encadrement et opérations

a- Encadrement et addition, encadrement et soustraction

Addition membre à membre

Règle : On peut additionner membre à membre deux encadrements de même sens.
\[ a < x < b \text{ et } c < y < d \implies a + c < x + y < b + d \]

Soustraction

💡 Attention : On ne peut pas soustraire membre à membre deux encadrements. Pour encadrer \(x - y\), on encadre d'abord \(-y\) (en changeant le sens), puis on additionne.
\[ c < y < d \implies -d < -y < -c \]
\[ \text{Puis : } a - d < x - y < b - c \]
Exemple : On donne \(2 < x < 5\) et \(1 < y < 3\).
Encadrer \(x + y\) puis \(x - y\).
Pour \(x + y\) : addition membre à membre. \(2 + 1 < x + y < 5 + 3\) \(3 < x + y < 8\) 3 < x + y < 8 Pour \(x - y\) : on encadre \(-y\) puis on additionne. \(1 < y < 3 \implies -3 < -y < -1\) \(2 + (-3) < x + (-y) < 5 + (-1)\) \(-1 < x - y < 4\) −1 < x − y < 4

b- Encadrement et multiplication, encadrement et division

Multiplication par un nombre

  • Si \(k > 0\) : \(a < x < b \implies ka < kx < kb\) (sens conservé).
  • Si \(k < 0\) : \(a < x < b \implies kb < kx < ka\) (sens changé).

Multiplication membre à membre

\[ a < x < b \text{ et } c < y < d \text{ avec } a, b, c, d > 0 \implies ac < xy < bd \]
💡 Attention : La multiplication membre à membre n'est valable que si tous les nombres sont positifs.

Division

Règle : Pour encadrer \(\dfrac{x}{y}\), on encadre d'abord \(\dfrac{1}{y}\) (inverse, en changeant le sens si \(y\) est de signe constant), puis on multiplie par \(x\).
\[ 0 < c < y < d \implies \frac{1}{d} < \frac{1}{y} < \frac{1}{c} \]
\[ \text{Puis si } 0 < a < x < b : \quad \frac{a}{d} < \frac{x}{y} < \frac{b}{c} \]
Exemple : On donne \(2 < x < 5\) et \(1 < y < 3\) (avec \(x, y > 0\)).
Encadrer \(xy\) puis \(\dfrac{x}{y}\).
Pour \(xy\) : multiplication membre à membre (tous positifs). \(2 \times 1 < xy < 5 \times 3\) \(2 < xy < 15\) 2 < xy < 15 Pour \(\dfrac{x}{y}\) : on encadre \(\dfrac{1}{y}\) puis on multiplie. \(1 < y < 3 \implies \dfrac{1}{3} < \dfrac{1}{y} < 1\) Multiplication membre à membre avec \(2 < x < 5\) : \(2 \times \dfrac{1}{3} < \dfrac{x}{y} < 5 \times 1\) \(\dfrac{2}{3} < \dfrac{x}{y} < 5\) 2/3 < x/y < 5

Résumé général

  • Comparaison : \(a < b \iff a - b < 0\).
  • Addition / soustraction : ajouter ou soustraire un même nombre conserve le sens.
  • Opposé : prendre l'opposé change le sens.
  • Multiplication par \(k\) : si \(k > 0\) sens conservé ; si \(k < 0\) sens changé.
  • Inverse : prendre l'inverse de deux nombres de même signe change le sens.
  • Carré : si positifs sens conservé ; si négatifs sens changé.
  • Racine carrée : sens conservé (nombres positifs).
  • Encadrement : addition membre à membre possible ; soustraction via l'opposé ; multiplication membre à membre si positifs ; division via l'inverse.
💡 Conseils :
  • Retiens la règle d'or : multiplier ou diviser par un nombre négatif change le sens de l'inégalité.
  • Pour la soustraction et la division, passe toujours par l'opposé ou l'inverse.
  • Vérifie toujours le signe des nombres avant d'appliquer une propriété de multiplication ou de carré.
  • Dans un encadrement, garde toujours les bornes dans le bon ordre (plus petit à gauche).
