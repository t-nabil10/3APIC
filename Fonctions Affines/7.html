VII. Méthode de résolution

  1. Calculer une image : remplacer \(x\) par la valeur dans \(f(x) = ax + b\).
  2. Calculer un antécédent : résoudre l'équation \(ax + b = y\).
  3. Déterminer \(a\) : utiliser \(a = \dfrac{f(x_2) - f(x_1)}{x_2 - x_1}\).
  4. Déterminer \(b\) : utiliser \(b = f(x_1) - a x_1\).
  5. Tracer la droite : placer \((0\,;\,b)\) et un deuxième point, puis tracer.
  6. Étudier le sens de variation : regarder le signe de \(a\).

Résumé général

  • Définition : \(f(x) = ax + b\) (fonction affine).
  • Coefficient directeur : \(a\) (pente de la droite).
  • Ordonnée à l'origine : \(b = f(0)\).
  • Représentation : droite passant par \((0\,;\,b)\).
  • Détermination de \(a\) : \(a = \dfrac{f(x_2) - f(x_1)}{x_2 - x_1}\).
  • Sens de variation : \(a > 0\) → croissante ; \(a < 0\) → décroissante ; \(a = 0\) → constante.
  • Cas particulier : si \(b = 0\), la fonction affine est linéaire.
💡 Conseils :
  • Pour déterminer \(a\), tu as besoin de deux points (ou deux images).
  • N'oublie pas que \(b = f(0)\) : c'est l'ordonnée du point d'intersection avec l'axe des ordonnées.
  • Pour tracer la droite, deux points suffisent : \((0\,;\,b)\) et un autre point calculé.
  • Le signe de \(a\) donne directement le sens de variation.
  • Ne confonds pas fonction affine (\(ax + b\)) et fonction linéaire (\(ax\)) : la linéaire est un cas particulier de l'affine.
