Résumé général

  • Définition : deux triangles sont isométriques s'ils sont superposables (côtés et angles égaux deux à deux).
  • Cas CCC : les 3 côtés sont égaux deux à deux.
  • Cas CAC : 2 côtés égaux + l'angle compris égal.
  • Cas ACA : 2 angles égaux + le côté compris égal.
  • Pas de cas AAA : 3 angles égaux ne suffisent pas (triangles semblables seulement).
  • Propriétés : même périmètre, même aire, angles et côtés correspondants égaux.
  • Application : démontrer des égalités de longueurs, d'angles, ou qu'un point est un milieu.
💡 Conseils :
  • Fais toujours un schéma et code les égalités connues sur la figure.
  • Vérifie bien que l'angle est entre les deux côtés (CAC) ou que le côté est entre les deux angles (ACA).
  • N'oublie pas le côté commun dans les démonstrations (ex. \(AI = AI\)).
  • Pour démontrer une égalité d'angles ou de longueurs, cherche d'abord une isométrie de triangles.
  • Ne confonds pas isométrique (même forme + même taille) et semblable (même forme, taille différente).
