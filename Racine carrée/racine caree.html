Racine Carrée — 3ème Année Collège

1. Définition de la racine carrée

Soit \(a\) un nombre positif ou nul. La racine carrée de \(a\), notée \(\sqrt{a}\), est le nombre positif ou nul dont le carré est égal à \(a\).

\[ \sqrt{a} = b \iff b^2 = a \text{ et } b \geq 0 \]
Conséquences :
  • \(\sqrt{a}\) n'existe que si \(a \geq 0\) (un nombre négatif n'a pas de racine carrée).
  • \(\sqrt{a} \geq 0\) pour tout \(a \geq 0\).
  • \(\left(\sqrt{a}\right)^2 = a\) pour tout \(a \geq 0\).
  • \(\sqrt{a^2} = |a|\) pour tout nombre réel \(a\).

2. Racine carrée d'un carré parfait

Un carré parfait est un nombre qui est le carré d'un entier. Sa racine carrée est un entier.

\[ \sqrt{n^2} = n \quad \text{pour } n \geq 0 \]

3. Propriétés de la racine carrée

a) Racine carrée d'un produit

Propriété : Pour tous nombres \(a \geq 0\) et \(b \geq 0\) :
\[ \sqrt{a \times b} = \sqrt{a} \times \sqrt{b} \]
Exemple : Calculer \(\sqrt{36 \times 25}\) de deux façons.
Méthode 1 : \(\sqrt{36 \times 25} = \sqrt{900} = 30\). Méthode 2 : \(\sqrt{36} \times \sqrt{25} = 6 \times 5 = 30\). √(36 × 25) = 30

b) Racine carrée d'un quotient

Propriété : Pour tous nombres \(a \geq 0\) et \(b > 0\) :
\[ \sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}} \]
Exemple : Calculer \(\sqrt{\dfrac{49}{16}}\).
\(\sqrt{\dfrac{49}{16}} = \dfrac{\sqrt{49}}{\sqrt{16}}\) \(= \dfrac{7}{4}\) √(49/16) = 7/4

c) Ce qui est FAUX avec la racine carrée

💡 Attention : En général, \(\sqrt{a + b} \neq \sqrt{a} + \sqrt{b}\).
ExpressionValeur exacteCe qu'il ne faut PAS faire
\(\sqrt{9 + 16}\)\(\sqrt{25} = 5\)\(\sqrt{9} + \sqrt{16} = 3 + 4 = 7\) ❌
\(\sqrt{25 - 9}\)\(\sqrt{16} = 4\)\(\sqrt{25} - \sqrt{9} = 5 - 3 = 2\) ❌

4. Simplification d'une racine carrée

Pour simplifier une racine carrée, on cherche à extraire les carrés parfaits contenus dans le nombre sous la racine.

Méthode

  1. Décomposer le nombre sous la racine en produit d'un carré parfait et d'un autre nombre.
  2. Appliquer la propriété \(\sqrt{a \times b} = \sqrt{a} \times \sqrt{b}\).
  3. Extraire la racine du carré parfait.
Exemple : Simplifier \(\sqrt{72}\).
\(72 = 36 \times 2\) (où \(36 = 6^2\) est un carré parfait). \(\sqrt{72} = \sqrt{36 \times 2}\) \(= \sqrt{36} \times \sqrt{2}\) \(= 6\sqrt{2}\) √72 = 6√2
Exemple : Simplifier \(\sqrt{50}\) et \(\sqrt{98}\).
\(50 = 25 \times 2\), donc \(\sqrt{50} = \sqrt{25} \times \sqrt{2} = 5\sqrt{2}\). \(98 = 49 \times 2\), donc \(\sqrt{98} = \sqrt{49} \times \sqrt{2} = 7\sqrt{2}\). √50 = 5√2 · √98 = 7√2

5. Réduire une somme de racines carrées

On peut additionner ou soustraire des racines carrées seulement si elles ont le même nombre sous la racine (facteur commun).

\[ a\sqrt{x} + b\sqrt{x} = (a + b)\sqrt{x} \]
Exemple : Réduire \(A = \sqrt{50} + \sqrt{98} - \sqrt{8}\).
\(\sqrt{50} = 5\sqrt{2}\) \(\sqrt{98} = 7\sqrt{2}\) \(\sqrt{8} = \sqrt{4 \times 2} = 2\sqrt{2}\) \(A = 5\sqrt{2} + 7\sqrt{2} - 2\sqrt{2}\) \(A = (5 + 7 - 2)\sqrt{2} = 10\sqrt{2}\) A = 10√2
💡 Attention : \(\sqrt{2} + \sqrt{3} \neq \sqrt{5}\). On ne peut pas additionner des racines différentes.

6. Développer et factoriser avec les racines carrées

On utilise les identités remarquables avec les racines carrées.

\[ (a + b)^2 = a^2 + 2ab + b^2 \]
\[ (a - b)^2 = a^2 - 2ab + b^2 \]
\[ (a - b)(a + b) = a^2 - b^2 \]
Exemple : Développer \(B = (2 + \sqrt{3})^2\) et \(C = (\sqrt{5} - \sqrt{2})(\sqrt{5} + \sqrt{2})\).
Pour \(B\) : \((2 + \sqrt{3})^2 = 2^2 + 2 \times 2 \times \sqrt{3} + (\sqrt{3})^2\) \(= 4 + 4\sqrt{3} + 3\) \(= 7 + 4\sqrt{3}\) B = 7 + 4√3 Pour \(C\) : \((\sqrt{5} - \sqrt{2})(\sqrt{5} + \sqrt{2}) = (\sqrt{5})^2 - (\sqrt{2})^2\) \(= 5 - 2 = 3\) C = 3

7. Encadrement d'une racine carrée

Pour encadrer \(\sqrt{a}\), on cherche deux carrés parfaits consécutifs encadrant \(a\).

Méthode : Si \(n^2 < a < (n+1)^2\) avec \(a > 0\), alors \(n < \sqrt{a} < n+1\).
Exemple : Encadrer \(\sqrt{30}\) entre deux entiers consécutifs.
On cherche les carrés parfaits autour de 30 : \(5^2 = 25\) et \(6^2 = 36\). Donc \(25 < 30 < 36\). En prenant la racine carrée (croissante sur \([0, +\infty[\)) : \(5 < \sqrt{30} < 6\). 5 < √30 < 6
Exemple : Encadrer \(\sqrt{50}\) entre deux entiers consécutifs, puis donner une valeur approchée à \(0{,}1\) près.
\(7^2 = 49\) et \(8^2 = 64\). Donc \(49 < 50 < 64\), soit \(7 < \sqrt{50} < 8\). \(\sqrt{50} = 5\sqrt{2} \approx 5 \times 1{,}414 \approx 7{,}07\). 7 < √50 < 8 · √50 ≈ 7,1

8. Équation \(x^2 = a\)

Règle :
  • Si \(a < 0\) : l'équation \(x^2 = a\) n'a aucune solution dans \(\mathbb{R}\).
  • Si \(a = 0\) : l'équation \(x^2 = 0\) a une seule solution : \(x = 0\).
  • Si \(a > 0\) : l'équation \(x^2 = a\) a deux solutions : \(x = \sqrt{a}\) et \(x = -\sqrt{a}\).
\[ x^2 = a \text{ avec } a > 0 \iff x = \sqrt{a} \text{ ou } x = -\sqrt{a} \]
Exemple : Résoudre l'équation \(x^2 = 9\) puis \(x^2 = 5\).
Pour \(x^2 = 9\) : \(x = \sqrt{9} = 3\) ou \(x = -\sqrt{9} = -3\). x = 3 ou x = −3 Pour \(x^2 = 5\) : \(x = \sqrt{5}\) ou \(x = -\sqrt{5}\). x = √5 ou x = −√5

Résumé général

  • Définition : \(\sqrt{a} = b \iff b^2 = a\) et \(b \geq 0\) (avec \(a \geq 0\)).
  • Carré parfait : \(\sqrt{n^2} = n\) pour \(n \geq 0\).
  • Produit : \(\sqrt{a \times b} = \sqrt{a} \times \sqrt{b}\) (pour \(a, b \geq 0\)).
  • Quotient : \(\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}}\) (pour \(a \geq 0\), \(b > 0\)).
  • Attention : \(\sqrt{a + b} \neq \sqrt{a} + \sqrt{b}\).
  • Simplification : extraire les carrés parfaits (ex. \(\sqrt{72} = 6\sqrt{2}\)).
  • Réduction : \(a\sqrt{x} + b\sqrt{x} = (a + b)\sqrt{x}\).
  • Identités remarquables : \((a \pm b)^2\), \((a - b)(a + b) = a^2 - b^2\).
  • Encadrement : si \(n^2 < a < (n+1)^2\), alors \(n < \sqrt{a} < n+1\).
  • Équation \(x^2 = a\) : si \(a > 0\), \(x = \sqrt{a}\) ou \(x = -\sqrt{a}\).
💡 Conseils :
  • Vérifie toujours que le nombre sous la racine est positif ou nul.
  • Apprends les carrés parfaits de 1 à 12 pour simplifier rapidement.
  • Ne confonds pas \(\sqrt{a + b}\) et \(\sqrt{a} + \sqrt{b}\) : c'est l'erreur la plus fréquente.
  • Pour simplifier, cherche le plus grand carré parfait contenu dans le nombre.
  • Pour réduire une somme, factorise par la racine commune.
