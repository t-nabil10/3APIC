III. Le caractère continu et les classes

1) Définition d'une classe

Définition : Une classe est un intervalle de la forme \([a\,;\,b[\) (ou \([a\,;\,b]\)).
  • \(a\) est la borne inférieure.
  • \(b\) est la borne supérieure.
  • L'amplitude de la classe est \(b - a\).

2) Le centre de classe

Définition : Le centre d'une classe \([a\,;\,b[\) est le nombre :
\[ c = \frac{a + b}{2} \]

C'est cette valeur \(c\) que l'on utilise pour calculer la moyenne (car on ne connaît pas les valeurs exactes à l'intérieur de la classe).

💡 Exemple : Pour la classe \([10\,;\,15[\), le centre est \(c = \dfrac{10 + 15}{2} = 12{,}5\).
Exemple 1 : Voici les tailles (en cm) de 20 élèves regroupées en classes :

1. Calculer le centre de chaque classe.
2. Calculer la taille moyenne.
1) Centres des classes : \([140\,;\,150[ \implies c_1 = \dfrac{140+150}{2} = 145\) \([150\,;\,160[ \implies c_2 = 155\) \([160\,;\,170[ \implies c_3 = 165\) \([170\,;\,180[ \implies c_4 = 175\) 2) Moyenne : L'effectif total est \(N = 4+8+6+2 = 20\). \(\overline{x} = \dfrac{4 \times 145 + 8 \times 155 + 6 \times 165 + 2 \times 175}{20}\) \(\overline{x} = \dfrac{580 + 1240 + 990 + 350}{20}\) \(\overline{x} = \dfrac{3160}{20} = 158\) Taille moyenne = 158 cm
