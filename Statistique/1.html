I. Vocabulaire de base

Définitions :
  • Une série statistique est un ensemble de données recueillies auprès d'une population.
  • Le caractère est la propriété étudiée (ex : âge, note, taille, poids...).
  • Effectif : nombre d'individus ayant une valeur donnée.
  • Effectif total (\(N\)) : somme de tous les effectifs.
  • Fréquence (\(f\)) : \(f = \frac{n}{N}\) (peut s'exprimer en %).

1) Les deux types de caractères quantitatifs

Type de caractèreDéfinitionExemples
Discret Prend des valeurs isolées (souvent des entiers). Nombre d'enfants, note sur 20, nombre de frères...
Continu Prend une infinité de valeurs dans un intervalle (mesures). Taille, poids, durée, température...
💡 Remarque : Pour un caractère continu, on regroupe les données en classes (intervalles) car il y a trop de valeurs possibles pour les lister une par une.
