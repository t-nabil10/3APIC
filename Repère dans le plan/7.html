VIII. Méthode de résolution

  1. Placer un point : lire l'abscisse sur \((Ox)\), l'ordonnée sur \((Oy)\).
  2. Calculer un milieu : faire la moyenne des abscisses et des ordonnées.
  3. Calculer une distance : appliquer la formule de Pythagore (repère orthonormé).
  4. Calculer les coordonnées d'un vecteur : soustraire les coordonnées de l'origine à celles de l'extrémité.
  5. Déterminer l'équation d'une droite : calculer \(a\) avec deux points, puis \(b\) avec un point.

Résumé général

  • Repère : deux axes gradués sécants en \(O\).
  • Repère orthonormé : axes perpendiculaires + même unité.
  • Point : \(M(x\,;\,y)\) — abscisse puis ordonnée.
  • Milieu : moyenne des coordonnées.
  • Distance : formule de Pythagore.
  • Vecteur \(\vec{AB}\) : \((x_B - x_A\,;\,y_B - y_A)\).
  • Droite verticale : \(x = k\) ; horizontale : \(y = k\) ; quelconque : \(y = ax + b\).
  • Coefficient directeur : \(a = \dfrac{y_B - y_A}{x_B - x_A}\).
💡 Conseils :
  • Écris toujours les coordonnées dans le bon ordre : abscisse d'abord, ordonnée ensuite.
  • Vérifie le signe des coordonnées selon le quadrant.
  • Pour calculer une distance, utilise un repère orthonormé.
  • Pour l'équation d'une droite, il faut deux points pour trouver \(a\), puis un point pour trouver \(b\).
  • N'oublie pas les parenthèses dans les calculs de distances (surtout avec des nombres négatifs).
